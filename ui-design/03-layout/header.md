# Header / Topbar

## Overview
Thanh điều hướng ngang luôn xuất hiện ở top của Application Shell.

## Layout
- **LEFT**: Sidebar toggle (☰), Breadcrumb (vd: `Logistic / Shipments`).
- **CENTER**: Global Search input hoặc trigger icon. Hỗ trợ shortcut (Cmd/Ctrl + K).
- **RIGHT**: Notifications (🔔), User Avatar + Menu.

## Dimensions
- Chiều cao compact: 56px – 64px. Tối đa không gian cho nội dung chính.
