# Table UX (Shipment)

## Overview
Là UI quan trọng nhất, dùng để duyệt lượng lớn dữ liệu.

## Features
- **Search & Filter**: Server-side kết hợp UI mượt mà.
- **Sort**: Hỗ trợ sort theo cột.
- **Column Visibility**: User bật/tắt cột hệ thống và Dynamic Fields (`show_in_list = true`).
- **Row Action**: Click dòng -> Detail. Nút `⋮` ở cuối dòng -> Edit, Duplicate, Archive.
- **Bulk Action**: Hiện thanh thao tác khi có dòng được chọn.
