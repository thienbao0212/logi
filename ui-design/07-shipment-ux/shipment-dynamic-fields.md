# Dynamic Fields UI

## Overview
Các trường tự động sinh ra dựa trên cấu hình của Admin.

## Render Behavior
- Sử dụng Design System chuẩn xác như System Fields.
- Text -> Input, Date -> DatePicker, Select -> Dropdown.
- Tự động tích hợp vào Filter bar nếu `filterable = true`.
- Tự động thành column trong Table nếu `show_in_list = true`.
