# Shipment Activity & History

## Overview
Hiển thị lịch sử các thay đổi như dạng timeline (Jira).

## UI Behavior
- List các sự kiện theo trình tự thời gian (mới nhất trên cùng).
- Có icon hoặc màu sắc khác nhau để phân biệt:
  - System changes (Ví dụ: `Bao changed ETA from 15/08 to 17/08`)
  - File uploads (`Hoa uploaded Invoice.pdf`)
  - User comments (Có khung nội dung comment)
