# Login Page

## Overview
Login là trang duy nhất không dùng Application Shell.

## Layout
- Thiết kế Professional, Minimal, Fast.
- Không sidebar, không header. Căn giữa màn hình.
- Fields: Email, Password. Button: "Sign in".

## States
- Default
- Loading ("Signing in...") - Disable submit để tránh click nhiều lần.
- Invalid credentials, Network error, Disabled, Success.
