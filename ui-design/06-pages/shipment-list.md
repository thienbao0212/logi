# Shipment List

## Overview
Không gian làm việc chính của nhân viên Logistics. Tối ưu UX tương tự Jira Work Items.

## Layout
1. Header / Breadcrumb
2. Page Header: Title + Primary Action `[+ Create Shipment]`
3. Toolbar: `[Global Search]` `[Status Filter]` `[More Filters]` `[Columns]` `[Export]`
4. Data Table: Full-width / Wide layout để hiển thị nhiều cột.

## Table UI
- Checkbox chọn nhiều (Bulk Action).
- Resize/Reorder columns.
- Sticky Header.
- Pagination.
